A web app that instantly rewrites your messages to sound **Professional**, **Friendly**, or **Concise** — powered by Python, Streamlit, and the OpenAI API.

---

## ✨ Features

- ✍️ **Three rewrite modes** — Professional, Friendly, Concise
- ⚡ **Instant results** — OpenAI GPT rewrites in under 2 seconds
- 📋 **Copy-paste ready output** — no extra formatting needed
- 💬 **Works for any text** — emails, Slack messages, LinkedIn DMs, customer replies
- 🧹 **Clean, minimal UI** — no clutter, just results

## 🚀 Run Locally

```bash
git clone https://github.com/sonnymay/ai-message-rewriter
cd ai-message-rewriter
pip install -r requirements.txt
streamlit run app.py
```

Set your API key:

```
OPENAI_API_KEY=your_openai_key
```
